Linguagem analisada: Mini-C (subconjunto da linguagem C)

Etapa 3 · Análise léxica: do código-fonte à sequência de tokens.

Código-fonte

Primeiros passos e subconjunto Mini-C
  1. Escolha um exemplo ou escreva seu programa. Você pode editar o texto.
  2. Selecione Analisar código para enviar o programa ao scanner.
  3. Compare o código com a tabela: um token é uma unidade classificada; o lexema é o texto reconhecido. Em int numero = 10;, numero é um lexema do tipo identificador.
  4. Use Token anterior e Próximo token para acompanhar a ordem de leitura. O destaque localiza o token já reconhecido; não é uma simulação de cada estado interno do scanner.
  5. Se houver erros, confira linha e coluna, corrija o código e analise novamente.

Palavras reservadas: int float if else. Identificadores usam letras ASCII, dígitos e _, sem começar por dígito.

Números: 10, 7.5. O sinal de menos é um operador separado. Strings, caracteres entre aspas, expoentes e hexadecimais estão fora do recorte.

Operadores: + - * / = == != < > <= >=. Delimitadores: ( ) { } ; ,.

Comentários // até o fim da linha e /* de bloco */ são ignorados, assim como espaços e quebras de linha. Comentários de bloco não podem ser aninhados.

Linha e coluna começam em 1; tabulação conta como uma coluna. A análise sintática ainda não está implementada: tokens válidos não garantem um programa válido.
