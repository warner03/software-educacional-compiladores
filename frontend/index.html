Linguagem analisada: Mini-C (subconjunto da linguagem C)

Etapa 4 · Do código aos tokens e à árvore sintática abstrata (AST).

Código-fonte

Até 10.000 caracteres; 64 níveis de aninhamento; AST com até 2.000 nós e altura 128.

Primeiros passos e subconjunto Mini-C
  1. Escolha um exemplo ou escreva seu programa. Você pode editar o texto.
  2. Selecione Analisar código. O scanner reconhece tokens; se não houver erro léxico, o parser confere a gramática e constrói a AST.
  3. Compare o código com a tabela: um token é uma unidade classificada; o lexema é o texto reconhecido. Em int numero = 10;, numero é um lexema do tipo identificador.
  4. Use Token anterior e Próximo token para acompanhar a ordem de leitura. O destaque localiza o token já reconhecido; não é uma simulação de cada estado interno do scanner.
  5. Na AST, abra os nós com clique, Enter ou Espaço. Use Localizar para destacar uma construção no código analisado, ou baixe a árvore em JSON. Em 10 + 5 * 2, a multiplicação é filha da adição.
  6. Se houver erros, confira linha e coluna, corrija o código e analise novamente.

Palavras reservadas: int float if else. Identificadores usam letras ASCII, dígitos e _, sem começar por dígito.

Números: 10, 7.5. O sinal de menos é um operador separado. Strings, caracteres entre aspas, expoentes e hexadecimais estão fora do recorte.

Operadores: + - * / = == != < > <= >=. Delimitadores: ( ) { } ; ,.

Comentários // até o fim da linha e /* de bloco */ são ignorados, assim como espaços e quebras de linha. Comentários de bloco não podem ser aninhados.

Gramática: declarações de uma variável int ou float, atribuições, expressões com sinais unários e operações aritméticas/relacionais, blocos e if/else com chaves obrigatórias. A vírgula é tokenizada, mas declarações múltiplas não são aceitas. Programa precisa de ao menos um comando ou bloco; {} é válido.

Laços, funções, vetores, strings, operadores lógicos e atribuições dentro de expressões ficam fora do recorte. A análise semântica (variáveis declaradas e tipos) será feita na Etapa 5.

Linha e coluna começam em 1; tabulação conta como uma coluna e Unicode conta por caractere. A posição final da AST é exclusiva. Erros sintáticos são recuperados em ; ou }; alguns erros podem impedir a detecção dos seguintes.
